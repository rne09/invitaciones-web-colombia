Por que web

Mas facil de compartir que una imagen o un PDF

Imagen/PDF

No confirma asistencia, no se actualiza facil y se pierde entre chats.

Invitacion web

Abre en cualquier celular, reproduce musica, lleva al mapa y confirma por WhatsApp.

Proceso

De idea a link en cuatro pasos

  1. 1Eliges plantilla

    Partimos de una base o creamos un estilo nuevo.

  2. 2Envias datos

    Nombres, fecha, lugar, musica, fotos y referencias.

  3. 3Personalizamos

    Ajustamos colores, textos, fondos y animaciones.

  4. 4Compartes link

    Recibes URL y QR para enviar a tus invitados.

Preguntas

Lo que normalmente pregunta un cliente

Cuanto tarda una invitacion?

Una plantilla base puede estar lista en 24 a 48 horas despues de recibir los datos completos.

El invitado necesita instalar algo?

No. Abre el link desde WhatsApp, navegador o codigo QR.

Se puede cambiar despues de enviada?

Si. Al ser una pagina web, se pueden corregir detalles sin reenviar una imagen nueva.

Puedo agregar fotos profesionales?

Si. Se puede enlazar un album de Pixieset o una galeria profesional del fotografo.
