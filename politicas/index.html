Politicas de servicio

Pagos

Para iniciar se solicita anticipo o pago completo segun el paquete. El enlace final se entrega cuando la invitacion queda aprobada.

Tiempos

Una plantilla base puede tardar de 24 a 48 horas despues de recibir datos completos. Personalizados y premium pueden requerir mas tiempo.

Cambios

Cada paquete incluye una cantidad de ajustes. Cambios grandes de estilo, nuevas secciones o cambios despues de aprobado pueden cotizarse aparte.

Contenido

El cliente debe enviar nombres, fecha, hora, ubicacion, textos, fotos, musica y referencias. Las fotos y canciones son responsabilidad de quien las suministra.
