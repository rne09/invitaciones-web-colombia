# Identidad visual — Invitaciones Web Colombia

Logo: sobre abierto color champán con una cinta terracota que se convierte en corazón.

## Colores
| Uso | Color |
|---|---|
| Verde esmeralda (fondo principal) | `#134843` |
| Champán (sobre / texto sobre verde) | `#f5e3bd` / `#f3e3bf` |
| Dorado (líneas del sobre) | `#d6a468` |
| Terracota (corazón) | `#e8744a` |
| Terracota oscuro (doblez de la cinta, texto sobre claro) | `#c4502f` |

## Tipografías
- Nombre "Invitaciones Web": **Playfair Display** (Google Fonts)
- "COLOMBIA": **Montserrat** 500, letras espaciadas

## Archivos
- `perfil-1080.png` — foto de perfil (Instagram, WhatsApp)
- `icono-oscuro.png` / `icono-claro.png` — solo el ícono, fondo transparente
- `horizontal-*.png` / `vertical-*.png` — ícono + nombre (oscuro = para fondos oscuros)
- `marca-de-agua.png` — blanca y semitransparente, para fotos
- `svg/` — las mismas versiones en vectores (para la web)

Reglas: no deformar el logo, usar solo estos colores y dejar espacio libre alrededor.
