# Ositos Team (Revelación de género)

Plantilla de muestra con datos ficticios. Apertura: **horizontal** · partículas: **confeti** · música propia sin derechos (`herramientas/musica_libre.py`, estilo `revelacion`).

Generada con `herramientas/crear_plantillas.py` (motor en `herramientas/motor/`). Para un cliente: copiar a `clientes/<evento>/`, editar `js/datos.js` (quitar `muestra`), el nombre en `index.html` y la música.
