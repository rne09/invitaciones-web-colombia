Este documento define la estructura concreta de la pagina publica. La meta es que cualquier disenador, IA o desarrollador pueda construir la primera version sin inventar desde cero.

### Como funciona

Titulo:

```text
Tu invitacion lista en pocos pasos
```

Pasos:

1. Eliges una plantilla.
2. Envias los datos del evento.
3. Personalizamos textos, colores, musica y fotos.
4. Revisas la invitacion.
5. Ajustamos detalles.
6. Recibes el link para compartir.

6. Preguntas frecuentes del evento.

## Estructura visual recomendada

Estilo general:

- Moderno.
- Claro.
- Elegante.
- Facil de leer.
- Primero movil.

Evitar:

- Que parezca solo una pagina de fotografia.
- Que todo sea rosado o infantil.
- Que la pagina sea muy cargada.
- Textos largos en la pantalla inicial.

Colores base sugeridos:

```text
Fondo: #FBF8F2
Texto oscuro: #272B33
Dorado: #B8944D
Azul gris: #607D9C
Verde suave: #8FA68E
Rosa viejo: #C9939B
```

Tipografias sugeridas:

- Titulos: Playfair Display, Cormorant Garamond o Fraunces.
- Texto: Inter, Lora o Cormorant Garamond.
- Detalles elegantes: Great Vibes o Pinyon Script, solo para acentos.

## Primer MVP web

Para la primera version construible:

- Una sola landing.
- Secciones internas con anclas.
- Catalogo inicial dentro de la misma pagina.
- 3 demos enlazadas.
- Boton de WhatsApp.
- Sin login.
- Sin base de datos.

Luego se expande a paginas individuales por evento.
