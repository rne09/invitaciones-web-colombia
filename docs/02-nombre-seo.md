# Nombre, SEO y posicionamiento

Este documento organiza el nombre de marca, usuario de Instagram, dominio y estrategia SEO inicial para vender invitaciones web.

## Principio SEO

La marca debe ser entendible para una persona y para Google. Debe decir rapido que se vende.

Google recomienda crear contenido pensando primero en los usuarios y ayudar a los buscadores a entender la pagina. Para este proyecto eso significa:

- Usar palabras claras: invitaciones, digitales, web, bodas, quinceanos, baby shower.
- Evitar nombres demasiado abstractos al inicio.
- Crear paginas especificas por tipo de evento.
- Usar titulos descriptivos y diferentes para cada pagina.
- Hacer que el sitio sea facil de navegar con enlaces de texto.

## Nombre recomendado

### Opcion principal

**Invitaciones Web Colombia**

Ventajas:

- Tiene la palabra exacta del servicio.
- Incluye ubicacion pais para busquedas locales.
- Sirve para todos los tipos de evento.
- Se entiende sin explicacion.
- Es util para Google, Instagram y WhatsApp.

Desventajas:

- Es mas funcional que emocional.
- Puede sentirse menos premium que una marca poetica.

Uso recomendado:

```text
Marca: Invitaciones Web Colombia
Instagram: @invitacionesweb.co
Dominio: invitacionesweb.co
```

### Opcion secundaria

**Invitaciones en Link**

Ventajas:

- Suena mas marca.
- Es facil de recordar.
- Explica que se entrega un enlace.

Desventajas:

- Tiene menos fuerza SEO directa que "Invitaciones Web Colombia".

Uso recomendado:

```text
Marca: Invitaciones en Link
Instagram: @invitacionesenlink
Dominio: invitacionesenlink.com
```

### Opcion mixta

**Invitaciones Web by Anderson Rene**

Ventajas:

- Mantiene SEO.
- Aprovecha la marca personal del fotografo.
- Sirve para cruzar con fotografia.

Desventajas:

- Si la novia tambien administra, puede sentirse menos marca compartida.
- Si el negocio crece, conviene que la marca no dependa de una sola persona.

## Diferenciador comercial

La competencia vende "tarjetas digitales". Este proyecto debe vender algo mas completo:

> Invitaciones web con experiencia de evento.

Diferenciadores:

- Diseno visual cuidado.
- Enlace listo para WhatsApp.
- Mapa, musica, contador y confirmacion.
- Version premium con mesas y galeria de invitados.
- Album profesional si Anderson cubre el evento.

## Propuesta de valor

Frase corta:

```text
Creamos invitaciones web que tus invitados pueden abrir, escuchar, confirmar y recordar.
```

Frase para la pagina:

```text
Disenamos invitaciones digitales personalizadas para eventos especiales, con musica, ubicacion, confirmacion por WhatsApp y opciones premium como mesas, galeria de invitados y album profesional.
```

## Antes de comprar dominio

Verificar:

- Disponibilidad del dominio.
- Disponibilidad del usuario de Instagram.
- Que no exista una marca registrada demasiado parecida.
- Que el nombre no limite el crecimiento a otros servicios.
