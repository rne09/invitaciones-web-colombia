# Referentes y estructura moderna

Investigacion realizada para orientar la pagina comercial de Invitaciones Web Colombia.

## Referentes revisados

- Wedvite: invitaciones con sobre animado, musica al abrir, RSVP, mapa, mensajes y un link compartible.
- Pinvite: propuesta enfocada en RSVP, mesas, regalos y album de fotos en vivo.
- InvitacionesDigitales.io: catalogo por tipo de evento con precios por categoria y app de gestion.
- InviteCount: flujo de tres pasos, plantillas editables, RSVP, mesas, galeria y precio unico por evento.
- Mentora Colombia: enfoque local colombiano, WhatsApp, anticipo, entrega rapida y paginas por evento.

## Estructura que conviene usar

1. Hero moderno con promesa clara, CTA a catalogo y CTA a WhatsApp.
2. Barra de confianza con beneficios cortos: sin app, link para WhatsApp, entrega rapida, responsive.
3. Vista de producto: celular/invitacion, RSVP, mapa, musica, galeria.
4. Catalogo de plantillas por evento.
5. Paquetes con precios claros.
6. Seccion premium: invitados, mesas, fotos, Pixieset y panel.
7. Proceso en pocos pasos.
8. Comparacion contra invitacion impresa o imagen/PDF.
9. FAQ.
10. CTA final.

## Decisiones para este proyecto

- No copiar plantillas ni assets de terceros.
- Crear tarjetas visuales originales inspiradas por categorias de mercado.
- Mantener el precio base de $50.000 COP.
- Mostrar un paquete premium para vender funciones avanzadas.
- Usar paginas SEO por evento para posicionar busquedas como "invitaciones web para bodas" e "invitaciones baby shower".
- Preparar la pagina para conectar luego con Netlify y un admin real.
