Terminos y privacidad

Uso de datos

Los datos del evento se usan para crear la invitacion, preparar el mensaje de confirmacion y entregar el enlace al cliente.

Fotos y musica

El cliente confirma que cuenta con permiso para usar las fotos, canciones o recursos que entregue para su invitacion.

Disponibilidad

La invitacion se publica en un servicio de alojamiento web seguro. De forma ocasional pueden presentarse breves interrupciones por mantenimiento.

Paquete premium

Las funciones de invitados, mesas y galerias se acuerdan y confirman directamente con cada cliente antes del evento.
