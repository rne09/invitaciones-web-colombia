Terminos y privacidad

Uso de datos

Los datos del evento se usan para crear la invitacion, preparar el mensaje de confirmacion y entregar el enlace al cliente.

Fotos y musica

El cliente confirma que cuenta con permiso para usar las fotos, canciones o recursos que entregue para su invitacion.

Disponibilidad

La invitacion se publica en plataformas externas como GitHub Pages o Netlify. Pueden existir ventanas de mantenimiento o cambios tecnicos.

Paquete premium

Las funciones de invitados, mesas y galerias requieren una fase con base de datos y reglas de acceso antes de usarse en produccion.
